## Design Context

### Users
Игроки Minecraft со смартфонов ищут живой сервер по режиму, версии и реальному онлайну. Владельцы серверов подтверждают права через временный ключ в MOTD.

### Brand Personality
Технический, уверенный, честный. Интерфейс говорит прямо и не маскирует рекламу под органический рейтинг.

### Aesthetic Direction
Тёмная нейтральная продуктовая поверхность, фирменный синий акцент, компактная информационная плотность. Главный визуальный артефакт сервера — настоящий широкий MOTD-баннер. Не использовать шаблонные маркетинговые секции, стеклянные карточки и декоративные градиенты.

### Implementation Defaults
Next.js 16 App Router, React 19, TypeScript strict, vanilla CSS с семантическими переменными, Lucide icons, Zod на границах API. Server Components по умолчанию; клиентский код только для интерактивности. Формы и списки пока собственные, без новой UI-библиотеки.

### Design Principles
- Сервер и его состояние важнее рассказов о продукте.
- MOTD, онлайн, версия и IP должны считываться за несколько секунд.
- Один синий акцент обозначает действие; статусы используют отдельные семантические цвета.
- Мобильный интерфейс сохраняет данные, а не превращает строки в декоративные карточки.
- Любая ошибка объясняет, что произошло и что пользователь может сделать дальше.
